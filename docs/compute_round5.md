# 第五轮：自适应M/K并行映射

日期：2026-10-26。工程E:/speed-up，ABI v5，生产默认4×4/TILE_K32/group32；8×8为研究配置。当前改动保留工作区，未提交、未推送。所有周期为实际RTL仿真，资源和时序为VU9P内部OOC，不是板卡或完整模型结果。

## 实现

新增MULTIROW_FOLD参数，默认开启。复用原有乘积通道，根据当前输出块的有效行数，选择能容纳这些行的最大2次幂K并行因子：8×8的M1/M2/M3或4分别使用8/4/2个K分片；M5..8回到原矩阵路径。最后一个M尾块也可折叠，例如M9的最后一行。4×4的M2使用2个K分片。

物理PE行按连续K分片分组。激活从对应逻辑行的cache bank选择，权重在逻辑行之间复用，部分和用同一归约树的对应子树合并。未增加MAC乘积通道。只在A_REUSE、脉动模式、ROWS为2次幂且tile/group/读取字宽满足约束时启用，不支持的参数保留原路径。MULTIROW_FOLD=0复现第四轮映射；GEMV_FOLD=0关闭折叠。广播和INT4打包研究路径与新映射共存。

没有扩大group、改变scale、舍入/饱和或外存packet合同。每组先精确归约，再执行原sx×sw与signed64合并。没有跨量化组混合部分和，也没有增加整图并发。

## 完整外存算子

只替换计算核，其他ABI v5顶层、FFN DMA、数据、存储服务相同。默认4×4，读延迟0/8/24、写延迟4及group12补充配置，共24组配对、48个完整65,536字节内存镜像任务。

8组周期减少，其余不变；所有读事务、有效字节、写入和B确认数量相同。M2的LINEAR最大1.01936倍、FFN最大1.01001倍。固定读延迟8拍时，LINEAR为2,143→2,136拍，FFN为8,720→8,691拍。它说明本轮映射改善已传到系统，但当前串行外存供数仍限制实际算子收益。不能把1.9–2.2倍核心收益套到FFN、模型token/s或板卡。
