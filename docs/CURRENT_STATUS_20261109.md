# 当前项目状态（2026-11-09 同步）

本文件整理截至本次同步可核对的结果。主要主系统实验完成于 2026-10-26，板测完成于 10-27，R8 独立核实验完成于 10-28；不把同步日期写成新的性能或硬件实验日期。

## 生产主线：R7 / ABI v5

主顶层为 `rtl/llm_graph_top.sv`，内部复用 `llm_top`；默认 4×4、TILE_K32、group32、64 位 AXI。单活动任务，阶段顺序执行，完成依赖真实写响应，错误先排空事务。

| 模块 | 已实现 | 当前范围 |
| --- | --- | --- |
| LINEAR | INT8 激活 × signed INT4 权重，分组部分和与 sx/sw 合并，Q16.16 舍入饱和 | 默认 M/N≤64、K≤4096 |
| FFN | gate/up → 中间读取 → SiLU/SwiGLU → 动态量化 → 写确认 → down | H≤64，中间桥≤512 元素 |
| KV | K/V/scale 平面，layer/head 元数据、追加/读取/清空与提交长度 | 有界缓存，不等于多层模型调度 |
| Attention | QK → 近似稳定 Softmax → AV → Y 写回 | 单 query、指定单 head，D≤64，可见前缀≤16 |
| 自动子链 | K/V 投影及量化 → KV 追加 → Q 投影/量化 → Attention | 有提交阶段与提交后恢复规则 |

R6 引入短 burst 与返回槽。R7 增加两个 16 字节权重行窗口、同 M/ml/group 的激活尺度缓存。相同任务和 AXI 服务下，8 组长 LINEAR 加速 1.90165–2.14307×；12 组小 LINEAR 为 1.14138–1.66706×，12 组小 FFN 为 1.08705–1.45475×。关闭两项缓存的 32 组对照复现 R6，并保留单项消融。

代表性 M8/N64/K4096、4×4/group32、读等待 8 拍/写等待 4 拍：1,152,380 → 537,724 拍，AR 87,040 → 22,528。权重有效字节保持 262,144，sx 读取由 32,768 → 2,048 字节。详见 [R7](system_round7.md)。

主系统历史内部 OOC：55,707 LUT、25,876 FF、403 DSP、7.5 BRAM36 等效，10 ns 下 WNS +0.042 ns、WHS +0.011 ns。该数字包含完整主系统，不能当作阵列单核资源或 CIV 整板资源。

## R8：独立单行流式核

`experiments/compute_round8_20261028/rtl/w4a8_gemv_stream.sv` 为独立研究核，64 个乘积通道、每拍最多 8 字节入口，保持组内归约、尺度和舍入规则。

- M1/N64/K2048：原核 10,615 拍，新核 9,510 拍，减少 10.41%；同批 openTPU64 为 9,564 拍。
- 20 组输入、55 次成功仿真、27,588 个部分和检查，包含非单位尺度、尾块、暂停、复位和失败探针。
- 内部 OOC 为 10,511 LUT、5,799 FF、76 DSP、4 BRAM36 等效；WNS +1.249 ns、WHS +0.007 ns。

它改变了入口流组织方式，尚未接入生产主系统外存读取器或上板。受控比较未统一三方数值格式、同器件面积、真实 DDR 或模型条件，不能据 54 拍差异宣称整机或模型领先。见 [R8 报告](../reports/compute_round8_20261028/单行计算核优化结果.md)。

## 实体板验证

2026-10-27，`xcvu9p_CIV-flgb2104-2-i` 上运行项目原有 `w4a8_compute_array` 与 `mac_pe`。8 组固定 ROM 输入，128 项板内比较一致（96 有效输出、32 无效位置清零），实际输出校验值 0x1f41。独立对照改错一项预期值，检出一项不一致。

40 秒物理采样含 72,184 点，解出 3 个正常帧和 2 个故障对照帧，CRC 全部通过。计算完成后反复上报保存结果，不能把帧数算成独立重算次数或持续计算压力测试。

本次采用内部低速时钟、片内固定输入及 DONE 专用信号，不使用计算侧 DDR/Aurora 或主机任务寄存器。主机读取状态、错误数与校验值，128 个原始输出没有逐项回传。它证明所测阵列在实际器件上正确运行，尚未证明完整加速器外部数据通路。

同日另有既有参考镜像的 DDR 回读与矩阵测试，属于参考后端验证。不能把它替换成自研完整 RTL 的结果。详情见 [板级说明](BOARD_VALIDATION.md)。
