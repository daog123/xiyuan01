# 自研阵列最小板级验证：复现说明

本实验的目标是验证当前项目 `w4a8_compute_array` 在实体 FPGA 上的计算正确性。生产计算源码 `mac_pe.sv`、`w4a8_wave.sv` 保持原样，增加独立的 ROM 输入、启动控制、比较器和结果回传模块。

## 数据和验收方式

计算配置：4×4 输出驻留脉动阵列，INT8 激活乘以符号扩展后的 INT4 权重，INT32 累加。使用 `vector_mode=0`、`BROADCAST_MAC=0`、`PACKED_MAC=0`。

8 组固定用例种子为 20261027，形状和全部数据位于 `vectors.json`。预期值由 Python 整数点积生成。每组检查完整 4×4 输出，共 128 项，其中 96 项为有效输出，32 项检查无效位置为零。包含随机数、边界值、全零、尾块、K=37 和运行暂停。

FPGA 内逐项比较实际累加器与预期 ROM，记录错误数和实际输出的滚动校验值。主机读回带 CRC8 的状态帧。主机没有逐项读回 128 个原始累加器值；正确性依据是 FPGA 内逐项比较、实际输出校验值，以及独立故障对照共同通过。

同一镜像中有两份阵列。正常实例应报告 errors=0；故障对照只把第一组第一个预期值翻转一位，应报告 errors=1。两份实际计算结果的校验值都应为 0x1f41。验收至少需要各 2 个 CRC 正确的结果帧。

## 器件与工程

- 目标：`xcvu9p_CIV-flgb2104-2-i`，IDCODE `0x04b35093`。
- 工具：本机 Vivado 2025.2。
- 时钟：STARTUPE3 的 CFGMCLK 经过 BUFGCE_DIV 除以 8。内部振荡器用于低速正确性验证，不用于性能测量。
- 普通引脚端口数：0。计算数据固定在 ROM，无计算侧 DDR/Aurora 接口。
- 结果：启动后通过专用 DONE 信号发送 Manchester 编码帧，由 C6 管理接口采样。
- Flash：只进行易失配置加载。

标准 `xcvu9p-flgb2104-2-i` 会生成 IDCODE `0x04b31093`，与本卡成功参考镜像不同。不要手工改写配置 ID 或绕过 CRC；使用 Vivado 正式提供的 CIV 型号构建。加载工具在打开硬件节点之前同时检查文件头和配置 ID。

`normalize_c6_header.py` 只将 `.bit` 文件头调整到参考加载流程使用的 128 字节配置数据偏移。它验证配置数据逐字节不变，并保存规范化前后的哈希及配置数据哈希。此前仅修改文件头对齐未能解决标准型号镜像的加载问题。

## 离线检查

保存的原始采样文件与解码 JSON 位于证据目录。无需连接板卡，可以运行：

```text
python verify_capture.py <done_samples.csv> --mode array --checksum 0x1f41
```

诊断镜像使用 `--mode diag`，其固定回传值为 status=13、cases=0、checksum=0xd10a、errors=0。静态 DONE 高电平不能通过解码验收。

## 服务器复现

服务器 10.12.131.149，固定 PCI `0000:84:00.0`，SDK card 0。本次从 sysfs 动态解析为 xdma4。服务器目录：`/root/fpga/xiyuan_midterm_20261027/array_bist`。

将复现包 `repro` 中的 C、Python 和 Shell 文件放在同一独立目录，将相应构建目录的 `array_selftest_c6.bit` 复制命名为 `diag.bit` 或 `array.bit`。校对 `SHA256SUMS.json` 后运行：

```text
bash run_physical.sh diag <diag.bit 的 SHA256>
bash run_physical.sh array <array.bit 的 SHA256>
```

脚本验证固定 PCI、管理版本和参考镜像哈希，使用本任务的单卡锁，创建私有设备节点。配置数据暂存后完整读回核对，再执行 SDK 同序列的易失加载，采样并解码。退出时恢复已验证的参考矩阵配置，执行复位并读取 ready 状态，清理自己的设备节点。

恢复依赖当前服务器上的参考镜像：

```text
/root/fpga/DynamicStream-HLS/phase1/matrix_v1/phase1_matrix_engine_v1.bit
SHA256=59358c612a7075ce1c8433ef26fe9bf4d5a7d30defdf501579195ce9baf2b984
```

原工程在 `E:/speed-up`，本轮独立实验在 `E:/speed-up/experiments/array_bist_20261027`。`run_local.py` 保存了本机工具和原工程的绝对路径。跨机器重新构建时需调整这两处路径；原始构建输入、哈希、Tcl、实现报告和 bitstream 已一并保留。

本实验只覆盖阵列整数计算及其最小验证电路。主机动态输入、计算侧 DDR、完整 LINEAR 量化输出以及整网推理需要后续接入。
