# 单行计算核供数优化与开源配对结果

2026年10月28日。目标用例M1/N64/K2048的新核RTL实测为 **9,510拍**，原核复测为 **10,615拍**，openTPU64复测为 **9,564拍**。新核减少1,105拍（10.41%），比openTPU少54拍（0.565%）。

## 实现与计时范围

新增`w4a8_gemv_stream`单行流式研究核，8个K分片×8个输出列，共64个物理乘积通道；入口保持64位、每拍至多8字节，两个尺度后处理lane，group32、INT8×INT4、组内精确归约、原尺度乘法及Q16.16舍入/饱和规则。目标范围M=1、1≤N≤64、1≤K≤4096，覆盖非单位和逐组变化尺度。

输入从空缓存开始：先装载完整激活和激活尺度，再按N块/K组连续装载权重和权重尺度。计时从任务接受之后开始，含全部数据输入、计算、归约、尺度处理和最终输出握手；复位准备不计入。测试台逐拍检查时钟计数、MAC数、各输入平面字节、量化组部分和与全部最终输出。

本次改变了本工程输入流的组织方式，并实现对应缓存、解包与控制RTL。它是单行专用流式核，用于替换受控实验中的M1执行路径。现有主系统和旧packet ABI保持原样，尚未将新流接口接入主系统外存读取器。报告中的周期不包含离线张量打包或真实DDR/PCIe服务，与原受控计算实验同属核级范围。

## 周期为何减少

原核按N块重复接收激活尺度，小段尺度包占用整拍；新核一次连续装入尺度，并在全部N块中复用。目标任务的权重65,536字节、激活2,048字节、权重尺度8,192字节均保持，激活尺度由1,024字节减为128字节。输入有效字节从76,800减为75,904。

原核9,984个入口beat对应79,872物理字节，其中3,072字节为包内空位。连续流将有效数据紧凑传输，75,904字节恰好占9,488拍，消除空位；输入拍数减少496拍。双权重缓冲衔接8×8计算与双路后处理，任务总周期超出输入拍数的部分由631拍降为22拍，再减少609拍。两部分合计减少1,105拍。

## 同一批数学输入的配对结果

| M / N / K | 原核复测 | 新流式核 | openTPU64复测 | 新核周期低于openTPU |
|---|---:|---:|---:|---:|
| 1 / 8 / 128 | 138 | 111 | 135 | 17.78% |
| 1 / 8 / 512 | 426 | 378 | 408 | 7.35% |
| 1 / 64 / 4096 | 21,111 | 18,998 | 19,084 | 0.45% |
| 1 / 64 / 2048 | 10,615 | 9,510 | 9,564 | 0.56% |

三套测试使用原受控实验中的相同确定性输入，激活/权重属于{-1,0,1}，数学尺度为1。本工程仍使用group32，openTPU仍使用原D64配置和通用尺度路径。openTPU固定提交810632e2e1d4961575a3c6f8f194abc8fc3f8fd3，64逻辑乘积通道，激活及其尺度预装载计时，权重/尺度共享每拍8字节的有限信用预算。本次重新运行其8组用例，未改上游算术、调度或供数限制。

## 数值与协议验证

- 20组输入，共55次成功运行。
- 覆盖完整INT8/INT4随机数、逐组非单位尺度、全零、正负饱和、N/K尾块及K4096。
- 独立检查27,588个量化组部分和；最终输出按独立整数参考逐项比较。
- 1,939次暂停下的输入/输出稳定性检查；在计算、后处理、输出阶段共6次复位后重跑。
- 非法几何、错误keep掩码均拒绝；拒绝后再次运行正确任务通过。
- 故意改错预期输出的负例触发数值检查失败，未出现通过标记。
- 冻结旧核及当前常规核均复现10,615拍；当前工程源文件与读取时保存的快照一致，未修改E盘源码。

## 复现材料

- `comparison.csv`：四组受控单行任务的前后及openTPU配对。
- `result.json`：结果、资源、验证数量和最终RTL哈希。
- `repro/rtl/w4a8_gemv_stream.sv`：本次新核。
- `repro/tb_stream.sv`：独立数值、流量和时钟检查。
- `repro/stream/`：输入、原始日志、结果CSV及故意破坏预期值的记录。
- `repro/frozen/`、`repro/current/`、`repro/open64/`：复测记录。
- `repro/implementation/`：资源、时序及布线报告。
- `repro/reference/`：复测依赖的原核及固定版本上游文件快照。

Windows环境需Vivado/XSim 2025.2和Python。进入`repro`后依次运行`python run.py prepare`、`python run.py baseline`、`python run.py open_baseline`、`python run.py stream`。综合可设置环境变量`ROUND8_OOC_WORK`指向一个英文路径工作目录，再运行`python run.py implement`；所有输入及核级仿真均在本地完成，不连接板卡。
